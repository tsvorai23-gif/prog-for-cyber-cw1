## Description

This Python program implements a basic security tool.

The program requires the user to authenticate before accessing a security menu. Once authenticated, the user can select from several security functions.

The program demonstrates the use of Python functions, variables, loops, conditional statements and user input.

## Features

The program includes four main functions:

### Security Event Counter

- Requests a password ten times.

- Counts correct and incorrect password attempts.

- Calculates the percentage of incorrect attempts.

- Displays an alert if more than 50% of attempts are incorrect.

### Brute-Force Simulation

- Uses a predefined password.

- Allows the user to guess the password.

- Counts the number of attempts.

- Stops when the correct password is entered or the maximum attempts are reached.

### Login Authentication

- Requests a username and password.

- Checks the entered credentials.

- Allows up to three failed login attempts.

- Displays an account freeze message after reaching the maximum attempts.

### Exit

- Ends the program.

- Displays a thank-you message.

## How to Run

### Requirements:

- Python 3 installed.

- Visual Studio Code or another Python-compatible editor.

### Instructions:

- Open the security-tool branch.

- Download or clone the repository.

- Open the task folder in Visual Studio Code.

- Open the Python program.

- Run the program using the terminal: "python security_tool.py"

- Replace the filename above if your Python file has a different name.

- Testing and Evidence

- The program should be tested using:

- Correct and incorrect passwords.

- More than 50% incorrect password attempts.

- Correct and incorrect brute-force guesses.

- Successful and failed login authentication.

- Three consecutive failed login attempts.

- Selecting the Exit option.
