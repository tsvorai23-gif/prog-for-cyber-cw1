## Description

This program acts as a basic security event logger. It records login attempts and displays information about each authentication event.

The program repeatedly requests a username and password until the correct credentials are entered.

Each login attempt displays an event log containing information about the attempt. This includes the event ID, username, IP address, event description and timestamp.

## Features

### The program demonstrates:

- Username and password authentication.

- Repeated login attempts using a loop.

- Conditional statements to check login credentials.

- Recording successful and failed login attempts.

- Generating event IDs.

- Recording timestamps for security events.

- Displaying security event logs.

- Example Event Log

## An example of the information recorded:

Username: admin
IP Address: 192.168.1.25
Event: Failed login
Timestamp: 2026-09-27 01:35:42

The actual event details depend on the program's implementation.
