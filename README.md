## Coursework Overview
This repository contains my Coursework 1 portfolio for the Programming for Cyber Security module.

The portfolio consists of five Python programming exercises covering fundamental programming concepts and their applications in cyber security.

Each exercise is maintained in its own dedicated Git branch. Each branch contains the Python implementation, an individual README file, a LICENSE file and screenshots showing evidence of testing.
Coursework Tasks

1.	Security Tool	A menu-driven security program featuring authentication, password checking and brute-force simulation. 

Branch = security-tool

2.	Security Event Logger	Records login attempts, including successful and failed authentication events.	

Branch = security-event-logger

3.	IP Address Validator	Uses a Python function and string operations to perform basic IPv4 format validation. 

Branch = ip-address-validator

4.	Security Incident Manager	Uses Python dictionaries to store, update and manage security incident information.	

Branch =security-incident-manager

5.	Cyber Security Utilities	Uses a separate Python module containing reusable password and IP validation functions and a password generator.	

Branch =cyber-security-utilitiesRepository Structure
